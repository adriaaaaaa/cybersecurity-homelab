# Ubuntu Server Setup

## Overview

This section documents the setup and administration of the Ubuntu Server 24.04 system used to host my cybersecurity homelab.

## Environment

- **Operating System:** Ubuntu Server 24.04
- **Hardware:** Dedicated mini PC
- **Remote Administration:** OpenSSH
- **Containerization:** Docker
- **Primary Services:** Prometheus, Grafana, Wazuh SIEM

## Configuration

The Ubuntu server serves as the central infrastructure host for monitoring and security tools.

Key setup tasks include:

- Installing and configuring Ubuntu Server
- Enabling SSH for remote administration
- Configuring local network connectivity
- Installing Docker and Docker Compose
- Managing services and containers
