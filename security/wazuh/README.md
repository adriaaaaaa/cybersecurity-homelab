# Wazuh SIEM Homelab

## Overview

This project documents the deployment and configuration of Wazuh SIEM in my cybersecurity homelab.

Wazuh provides centralized security monitoring, log analysis, endpoint visibility, and threat detection across my Ubuntu Server and Windows desktop.

The environment uses Wazuh 4.14.8 deployed through Docker Compose on Ubuntu Server 24.04.

## Technologies Used

- Wazuh SIEM 4.14.8
- Docker and Docker Compose
- Ubuntu Server 24.04
- Windows
- Windows Event Logs
- Linux system logs

## Architecture

The environment consists of three primary Wazuh components:

| Component | Purpose |
|---|---|
| Wazuh Manager | Receives and analyzes endpoint security events |
| Wazuh Indexer | Stores and indexes security alerts |
| Wazuh Dashboard | Provides centralized security visualization and investigation |

### Monitored Endpoints

| Agent | Operating System | Connection Status |
|---|---|---|
| ubuntu-homelab | Ubuntu Server | Active |
| windows-desktop | Windows | Active |

Both endpoints send security events to the Wazuh Manager.

## Deployment

Wazuh was deployed using the official single-node Docker Compose configuration.

The deployment included:

1. Configuring the Wazuh Manager, Indexer, and Dashboard containers.
2. Configuring authentication between Wazuh services.
3. Verifying container health and service connectivity.
4. Installing a Wazuh agent on the Ubuntu host.
5. Installing a Wazuh agent on the Windows desktop.
6. Confirming both agents were active.
7. Verifying that security alerts appeared in the Wazuh Dashboard.

## Security Monitoring

The environment supports centralized investigation of security alerts generated by monitored endpoints.

### Windows Authentication Monitoring

I performed a controlled Windows authentication test to verify Wazuh's detection capabilities.

- Generated an intentional failed login.
- Confirmed Windows Event ID 4625.
- Located the corresponding event in Wazuh Threat Hunting.
- Investigated the alert's severity, logon type, and authentication information.

The investigation identified a level 5 alert associated with an interactive failed login.
